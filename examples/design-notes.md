# 笔记社区 MVP 设计规格

用户通过演示账号登录，发布文本笔记，浏览列表并发表评论。首版使用 SQLite。

| 编号 | 模块 | 约定 |
| --- | --- | --- |
| DS01 | 账号与数据 | POST /sessions 验证账号，保存 user、note、comment。 |
| DS02 | 发布 | POST /notes，登录后保存标题、正文、作者和时间。 |
| DS03 | 查询 | GET /notes 倒序查询，GET /notes/{id} 查询详情。可用预置数据先开发。 |
| DS04 | 评论 | POST /notes/{id}/comments，登录后评论已有笔记。 |

未登录的发布与评论返回401，笔记不存在返回404。
验收覆盖登录、发布、列表、详情和评论完整流程及上述错误分支。
图片、推荐、关注和私信留待后续。本期只含文本。
